# Portfolyo editörü kullanımı

`Portfolyo-Editorunu-Ac.cmd` dosyasına çift tıklayın. Editör ve canlı önizleme tarayıcıda açılır.

- Soldan **Ana sayfa** veya **Proje sayfası** seçin.
- Blokların görünürlüğünü açıp kapatın; yukarı/aşağı düğmeleriyle sıralarını değiştirin.
- Bir bloğu seçerek görünümünü (`standard`, `muted`, `accent`) ve dikey boşluğunu (`compact`, `standard`, `spacious`) düzenleyin.
- **Mobil görünüm** düğmesi önizlemeyi telefon genişliğine alır.
- **Kaydet**, değişiklikleri yalnızca yerel YAML içerik dosyalarına yazar.
- **Kaydet ve commit et**, kaydeder ve yalnızca `feature/portfolio-renewal` gibi bir `feature/` dalında seçili düzenleme dosyalarını commit eder. `main` dalındayken editör kaydetmez.

Pages CMS, GitHub üzerindeki aynı içerik ve medya dosyalarını uzaktan düzenlemek içindir. Sürükle-bırak benzeri canlı önizleme yerel editörde bulunur; Pages CMS kaydettiğinde kendi GitHub commit akışını kullanır.

Editörü kapatmak için onu çalıştıran komut penceresinde `Ctrl+C` tuşlarına basın.
